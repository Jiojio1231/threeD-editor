# 3D model assets

- `server-rack.glb`: [Server Rack](https://grab3d.com/models/electronics/server-rack/), Grab3D, CC0 1.0.
- Optional free door model: [Roller Shutter Door](https://grab3d.com/models/buildings/roller-shutter-door/), Grab3D, CC0 1.0. Download the GLB and use the in-app model importer.

The room shell and its double-door assembly use parameterized Three.js geometry so they can be resized with the room dimensions.
